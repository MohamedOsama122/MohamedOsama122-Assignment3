# CSharpBasicsAssignment

This project is a C# console application created to practice basic C# concepts.

## Topics Covered

- Project structure and `.csproj`
- C# variables and data types
- Implicit and explicit casting
- Integer and floating-point division
- Boxing and unboxing
- Parsing with `Parse` and `TryParse`
- Value types and reference types
- Stack and Heap concepts
- Scope
- Compound assignment operators
- Bitwise and logical operators
- XOR and LeetCode 136: Single Number
